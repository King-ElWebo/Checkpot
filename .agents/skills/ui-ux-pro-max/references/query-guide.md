# Query and Result Guide

## Query construction

Use this order:

`<site type> <industry> <audience> <brand adjective 1> <brand adjective 2> <brand adjective 3>`

Good example:

`multi-page specialty coffee roastery design-conscious consumers warm editorial tactile premium`

Avoid vague queries such as `modern beautiful website`. Do not include a style name unless the customer explicitly requested it; otherwise the knowledge base should recommend the style.

## Result mapping

Map the generated output into `docs/DESIGN-SYSTEM.md`:

| Generated area | Project decision |
| --- | --- |
| Pattern | Page rhythm, section order, and conversion structure |
| Style | Surface treatment and component character |
| Colors | Semantic color roles and accessible pairings |
| Typography | Display/body families, hierarchy, weights, and fallbacks |
| Key effects | Allowed motion and visual effects |
| Avoid | Explicit design anti-patterns for the project |

Record why a generated recommendation was accepted, adjusted, or rejected when the choice is not obvious from the customer brief.
